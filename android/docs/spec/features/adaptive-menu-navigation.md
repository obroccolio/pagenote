# Android 自适应桌面菜单导航

> 状态：导航方案已由发起人确认；本文件只规定菜单导航壳，不代表桌面全部命令已移植完成。
> 当前设备范围：仅小米平板 5 Pro（Android 14/API 34）。手机抽屉和其他窗口/设备形态保留为后续参考，不属于当前支持或测试门槛。

## 目标

把 pagenote 桌面端熟悉的菜单分组放到 Android 阅读工作区旁边，减少顶部横向工具条对 PDF/笔记空间的挤占。菜单使用 Compose 原生触控交互，保留当前项目、页码、阅读视口、笔迹草稿和笔记草稿。

## 响应式行为

- 窗口宽度小于 600dp 时，顶栏提供菜单按钮；点击打开模态抽屉。选取可执行命令后抽屉关闭；返回键关闭抽屉，不改变阅读状态。
- 窗口宽度不小于 600dp 时，菜单在工作区左侧常驻显示。侧栏默认展开，并提供收起/展开按钮；收起时保留可访问的分组入口，选中分组仍能查看该组命令。
- 断点基于当前 Compose 窗口可用宽度，不根据设备品牌、型号或方向判断。
- 菜单宽度从工作区扣除后，阅读区仍按已有规则在至少 840dp 可用宽度时左右并排，否则上下排列。
- 展开/收起、抽屉开关或选择分组不得重建项目会话，不得清空 PDF 缩放/滚动、当前页、笔迹或笔记草稿。

## 菜单分组

分组名称及顺序沿用桌面信息架构：文件、AI 批注、编辑、段落、格式、插入、阅读、手写批注、Word 编辑、设置、使用说明。Android 上已有的命令复用现有 ReaderHome 回调；暂未移植的桌面命令仍显示在对应分组中，使用禁用态和简明原因，不伪装成可执行操作，也不静默删除分组。

首个导航切片接线已有能力：

| 分组 | Android 已接线命令 |
| --- | --- |
| 文件 | 打开项目、新建项目 |
| AI 批注 | AI 讲解、Agent 任务、批注列表、审阅、交接 |
| 阅读 | 上一页、下一页、整页 OCR、区域 OCR、缩放、适宽、适页 |
| 手写批注 | 笔、荧光笔、橡皮、批注模式、撤销、重做、清空本页 |
| 设置 | 阅读设置 |

顶栏持续显示 `page / total`，该状态也是直接页码跳转入口；校验、脏笔记保存与切页基线见 `page-jump.md`。

其余桌面分组先显示明确的未接线状态，后续按对应 Android 功能 SPEC 逐项移植；该状态不等于这些桌面能力从终态范围移除。当前页/页数可留在工作区顶栏作为持续可见状态。

## 视觉与无障碍

- 沿用桌面视觉 token：浅色强调色 `#185abd`、深色强调色 `#8bb8ff`，页面/表面/文字颜色取自 `desktop-ui-and-office-parity.md`；不另建一套品牌色。
- 菜单浅色表面使用 `#f5f8fd`、主文字 `#253247`、次级文字 `#687587`、分隔线 `#dfe6f0`；深色表面使用 `#22252b`、主文字 `#e7eaf0`、次级文字 `#aab4c3`、分隔线 `#414854`。这些 token 只作用于菜单，不覆盖阅读主题或文档像素。
- 使用 Android 原生 sans-serif fallback 和 Material 3 语义色，保持桌面紧凑分组、清晰分隔与克制圆角。
- 每个图标分组有可读标签/TalkBack 描述；禁用命令能通过辅助语义读出原因；点击目标满足触控尺寸。
- 菜单在浅色、深色及中英文设置下均保持可读；不遮挡状态栏、导航栏或页面交互层。

## 验收

- When 窗口宽度低于 600dp，用户 shall 能从顶栏打开/关闭菜单抽屉，并在命令执行后回到原阅读状态。
- When 窗口宽度至少 600dp，用户 shall 能使用常驻侧栏选择菜单分组、执行已有命令并收起/展开侧栏。
- When 窗口宽度跨越 600dp 断点或设备旋转，应用 shall 切换抽屉/侧栏形态且保留项目、页码、视口和未保存草稿。
- When 某菜单命令尚未移植，应用 shall 显示禁用状态及原因，不得无响应或调用不存在的动作。
- When 菜单状态变化，应用 shall 不重置已有 PDF/笔记双栏自适应布局及手写笔输入状态。

## 测试

- JVM：断点策略在 599dp/600dp 两侧返回正确导航形态。
- Compose 仪器：目标平板侧栏展开/收起、仍可选分组、禁用项原因和当前页/缩放/笔记草稿保留。
- Android 14/API 34 平板 AVD 仅用于平台级回归；不新增 Pixel Tablet/API 35 或手机尺寸 AVD 门槛。
- 目标小米平板实机确认横屏菜单侧栏不遮挡阅读区；其他设备/窗口形态暂不验收。
